# mini_project-3_pemogramanWEB
Project ini sebuah aplikasi berbasis web yang digunakan untuk mengelola data produk elektronik, seperti laptop, iPad, dan aksesori. Aplikasi ini membantu pengguna mencatat barang masuk dan keluar, memantau jumlah stok, serta melihat riwayat transaksi agar pengelolaan persediaan barang lebih mudah, rapi, dan terorganisir.
